# CivicResolve AI

## AI-Powered Public Grievance Analysis & Resolution Recommendation Platform

CivicResolve AI transforms citizen complaints into actionable insights using AI, NLP, verification signals, priority analysis, department recommendation, and resolution recommendations.

## Problem Statement

AI-04: Develop an AI-powered public grievance analysis and resolution recommendation platform.

## Core Features

- AI complaint classification
- Sentiment analysis
- Priority assessment
- Department recommendation
- Resolution recommendation
- Duplicate grievance detection
- Complaint verification confidence
- Administrative analytics dashboard

## Technology Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
- NLTK
- Plotly
- SQLite

## AI Usage

AI-assisted development tools were used during the hackathon. The team reviewed, tested, modified, and integrated the generated material into the final implementation.
